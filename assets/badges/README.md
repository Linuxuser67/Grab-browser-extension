# Badge assets

- `get-it-on-flatpark.svg` is the unmodified official FlatPark badge from [flatpark/flatpark](https://github.com/flatpark/flatpark/blob/main/site/public/badges/get-it-on-flatpark.svg). Link it to Grab's [FlatPark listing](https://flatpark.org/apps/io.github.linuxuser67.Grab/).
- `get-the-addon-firefox.svg` is Mozilla's unmodified official [Get the Add-on badge](https://blog.mozilla.org/addons/files/2020/04/get-the-addon-fx-apr-2020.svg). Link it to the [Grab Firefox Add-ons listing](https://addons.mozilla.org/en-US/firefox/addon/grab-extension/).
- `github-releases.svg` is original project artwork. Link it to the latest extension release.
